# Security policy

This is a personal research project (a halal quantitative trading research platform). It trades on an
Interactive Brokers **paper** account only; it never holds live-trading credentials or real money.

If you find a security problem (for example a leaked secret, an unsafe default, or a way to bypass the
risk engine or the paper-only guards), please report it privately using GitHub's
"Report a vulnerability" button on this repository's Security tab, and do not open a public issue.

Please do not include real credentials, account numbers or licensed data in any report.
